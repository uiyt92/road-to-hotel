# 5 Points 거시 전략론 HTML 덱 리디자인 사양

## 1. 목표

기존 30장 HTML 강의안의 내용 구조와 발표 기능은 유지하되, 시각 언어를 전면 교체한다. 결과물은 ‘카드형 웹 문서’가 아니라 외부 강의 무대에서 한눈에 읽히는 현대적인 전술 브리핑 덱이어야 한다.

핵심 판단 기준은 다음과 같다.

- 슬라이드를 3초만 봐도 중심 메시지가 보인다.
- 도식을 설명하기 전에 위치, 방향, 역할, 다음 행동이 읽힌다.
- 장식용 SVG나 의미 없는 도형이 없다.
- 한 장에는 핵심 문장 하나와 주요 시각화 하나만 남긴다.
- 발표자의 상세 설명은 발표자 노트로 이동한다.

## 2. 유지할 내용

다음 5 Points와 하위 이론은 삭제하거나 다른 개념으로 치환하지 않는다.

1. 마인드셋
2. 상황 읽기
3. FRAME CONTROL
4. TEAM PLAYING
5. 협상력(화술)

필수 하위 내용:

- 권력의 흐름, 텐션, 의미 부여, 안전
- 친구 프레임과 남녀 프레임의 전환
- 아버지–어머니 역할
- 명분 + 동선 + 기세
- 관찰 → 판단 → 행동
- 사례, 롤플레이, 피드백 루브릭
- 성과 기준: 1차는 감정적 반응, 최종은 긍정적 의미와 다음 가능성, 최악은 무가치
- 분노는 목표가 아니라 안정시켜야 할 신호
- 동의, 경계, 취기, 거절 비용에 관한 안전 원칙

## 3. 확정된 시각 방향

### 3.1 스타일

`C1 스위스 택티컬`을 기본으로 한다.

- 현대적인 스포츠 브랜드와 전술 브리핑의 속도감
- 과장된 밀리터리 장식이나 오래된 스포츠 방송 스타일은 피한다.
- 정보의 위계를 큰 타이포, 선명한 방향, 제한된 색으로 만든다.
- 카드의 반복 대신 화면 전체를 하나의 구도로 사용한다.

### 3.2 폰트

- 본문과 제목: Noto Sans KR Variable
- 영문 레이블과 숫자도 같은 패밀리 안에서 굵기와 자간으로 구분한다.
- Arial Black, 맑은 고딕 중심의 기본 오피스 문서 느낌을 제거한다.
- 최종 단일 HTML에는 강의안에 사용된 글자만 서브셋한 WOFF2를 포함한다.

권장 굵기:

- 제목 800~900
- 핵심 결론 700~800
- 본문 450~550
- 영문 레이블 700, 넓은 자간

### 3.3 색상

- 배경: 잉크 블랙 `#111319`, 웜 아이보리 `#F4F2ED`
- 전진·핵심: 옐로 `#FFCA2E`
- 밸런싱·안정: 틸 `#00B3AA`
- 반발·위험·경계: 코럴 레드 `#FF5138` 또는 로즈 `#E95370`
- 한 슬라이드의 주 강조색은 원칙적으로 하나만 사용한다.

### 3.4 사진

사진은 사용하지 않는다. 표지를 포함한 30장 전체를 타이포, 면, 선, 좌석 배치, 전열, 단계 흐름과 같은 코드 기반 시각 요소로 구성한다.

- 생성형 사진, 스톡사진, 배경 사진 모두 사용하지 않는다.
- 사진 없이도 장면과 이동 방향이 느껴지도록 구도를 설계한다.
- 인물은 장식용 캐릭터가 아니라 위치와 역할을 보여주는 최소 형태로만 표현한다.

## 4. 도식 설계 원칙

### 4.1 기본 문법

도식은 다음 중 하나의 구조만 사용한다.

1. `관찰 → 판단 → 행동`
2. `상황 전 → 개입 → 상황 후`
3. `위치 → 역할 → 이동 방향`
4. `최악 → 1차 기준 → 목표 → 최종 성공`

형태만 봐서는 뜻을 알 수 없는 원, 궤도, 저울, 추상 네트워크, 장식 화살표는 사용하지 않는다. 모든 선과 화살표에는 행동 또는 변화의 의미를 직접 표기한다.

### 4.2 아버지–어머니 전열

팀플레이 파트의 중심 도식은 군대 전열을 닮은 4인 이동 구도다.

`후위 어머니 → 여성 A · 여성 B → 전위 아버지 → 목적지`

- 아버지·리더는 전위에서 목적지를 정하고 길을 연다.
- 아버지는 반발과 공격을 먼저 받는다.
- 여성 두 명은 중간 대열에서 이동하며 속도와 부담 신호를 보낸다.
- 어머니·밸런서는 후위에서 뒤처지는 사람을 챙긴다.
- 어머니는 아버지가 공격당할 때 중재, 의도 번역, 보호를 수행한다.
- “떨어져 나가도 나는 간다”는 방향에 동의하지 않는 사람을 억지로 끌고 간다는 뜻이 아니다. 이탈과 거절은 존중하되 리더가 반발 때문에 자기 방향까지 잃지 않는다는 뜻이다.

### 4.3 성과 기준

기존 2×2 매트릭스 대신 왼쪽에서 오른쪽으로 읽는 네 단계로 표현한다.

1. 무가치: 아무 감정이나 기억할 이유가 없음 — 최악
2. 반응 발생: 호감, 분노, 경계 등 감정이 움직임 — 1차 기준
3. 긍정적 의미: 재미, 호감, 신뢰로 의미가 바뀜 — 목표
4. 다음 가능성: 연락, 다음 약속, 대화가 이어짐 — 최종 성공

분노는 2단계의 신호일 뿐 목표가 아니며, 경계가 나오면 즉시 안정시킨다는 문장을 함께 배치한다.

## 5. 슬라이드 구도 유형

전체 30장은 다음 여섯 구도 유형 안에서 설계한다.

1. **표지**: 초대형 제목 + 4인 전열을 암시하는 최소 구도 + 짧은 선언
2. **섹션 오프너**: 초대형 숫자와 핵심 문장, 설명 없음
3. **원리 슬라이드**: 핵심 개념 하나 + 대형 도식 하나
4. **판단 슬라이드**: 관찰 → 판단 → 행동의 가로 흐름
5. **사례 슬라이드**: 시간 또는 장면 순서에 따른 전후 변화
6. **실습 슬라이드**: 해야 할 행동, 시간, 관찰 기준만 크게 표시

동일한 카드 3~4개를 나열하는 구도는 사용하지 않는다. 목록이 필요하면 하나의 축, 전열, 타임라인, 단계 흐름으로 변환한다.

## 6. 밀도와 문장

- 제목은 두 줄 이내
- 화면 본문은 최대 45~60자 수준을 목표로 한다.
- 긴 설명, 연구 해설, 진행자 멘트는 발표자 노트로 이동한다.
- 각 슬라이드 하단에는 발표자가 반복할 결론 한 문장만 둔다.
- 영문은 장식이 아니라 섹션 레이블과 단계 구분에만 사용한다.
- 번역투 표현을 피하고 현장에서 바로 말할 수 있는 한국어를 사용한다.

## 7. 인터랙션과 출력

기존 HTML 기능은 유지한다.

- 좌우 화살표와 Space로 이동
- N: 발표자 노트
- O: 전체 보기
- F: 전체화면
- 해시 기반 위치 복원
- 인쇄 시 30페이지
- 외부 네트워크 요청 없음

발표 UI는 기본 상태에서 완전히 숨기고 마우스 이동 또는 키보드 입력 시에만 잠시 나타난다. 인쇄물에는 UI가 포함되지 않는다.

## 8. 구현 범위

- 기존 30장 HTML의 시각 레이아웃 전면 교체
- 발표자 노트와 핵심 콘텐츠 유지
- 카드형 구도 및 오래된 SVG 제거
- 사진을 사용하지 않는 타이포·도식 기반 표지 제작
- Noto Sans KR 서브셋을 단일 HTML에 내장
- 직관적인 도식 시스템으로 핵심 이론 재설계
- 대표 화면 검토 후 전 장 적용

기존 PPTX와 PDF는 백업으로 유지하며, 리디자인 대상은 HTML 강의안이다.

## 9. 검수 기준

- 총 30장과 발표자 노트 30개 유지
- 3가지 화면 크기에서 텍스트 잘림 없음
- 30장 전체 사진 0장
- 외부 요청 0건
- 인쇄 결과 30페이지
- 조작 버튼이 발표 화면을 방해하지 않음
- 모든 도식에서 선과 화살표의 의미가 문장으로 표시됨
- 아버지–여성 2명–어머니의 전열 위치가 정확함
- 5 Points와 안전 원칙이 누락되지 않음
