# 1주차 챕터 표지 및 협상력 분리 설계

## 목적

현재 HTML 강의 자료에 마인드셋, 상황 읽기, Frame Control, Team Playing, 협상력의 독립 챕터 표지를 추가한다. 1주차의 실제 학습 범위는 1~4번으로 제한하고, 협상력은 2주차 예고로만 남긴다.

## 최종 구조

- 전체 분량: 32장
- 1주차 본문: 마인드셋, 상황 읽기, Frame Control, Team Playing
- 2주차 예고: 협상력
- 각 포인트 앞에 내용이 없는 독립적인 전면 챕터 표지 1장 삽입
- 협상력 표지 뒤에는 협상력 이론이나 실습을 배치하지 않음

## 챕터 표지 체계

모든 챕터 표지는 같은 골격을 사용한다.

1. 화면을 지배하는 두 자리 번호 `01`~`05`
2. 한글 파트명과 영문 보조명
3. 해당 파트가 해결하는 문제를 한 문장으로 제시
4. 하단 5단계 진행 표시에서 현재 위치 강조
5. 기존 덱의 어두운 그리드, 노란 포인트, Noto Sans KR 계열을 유지

표지 문구는 다음과 같다.

- `POINT 01 · 마인드셋` — 반응에 끌려가지 않아야 판 전체를 볼 수 있다.
- `POINT 02 · 상황 읽기` — 권력·텐션·의미·안전으로 지금 필요한 결정을 찾는다.
- `POINT 03 · FRAME CONTROL` — 관계와 자리의 의미를 다시 정의한다.
- `POINT 04 · TEAM PLAYING` — 전위는 길을 열고, 후위는 대열을 지킨다.
- `POINT 05 · 협상력` — 말보다 먼저, 제안이 받아들여질 구조를 만든다. `2주차에서 계속`

협상력 표지는 진행 표시의 5번을 윤곽선으로 처리하고 `WEEK 02 / NEXT` 배지를 붙여, 미학습 영역임을 명확히 한다.

## 기존 내용 변경

### 삭제

- 기존 협상력 이론 3장: 구장·나·상대, 명분·동선·기세, 선택 가능한 제안

### 교체

- `90초 안에 나와 내 윙을 설명하라` → 관찰과 해석을 분리하는 90초 실습
- `분위기는 좋은데 다음 단계가 애매하다` → 전위·후위 역할 교대 실습
- 5항목 피드백 루브릭 → 1주차 4항목 평가 + 협상력 `2주차` 잠금 표시
- 전체 지도와 마지막 복습 → 1~4번 `WEEK 01`, 5번 `WEEK 02`로 구분

### 유지

- 도입부, 성공 기준, 사례, 근거, 안전 규칙
- 아버지 전위 / 여성 2명 중간 / 어머니 후위 전열
- 동의와 안전을 판단 체계 안에 포함하는 원칙

## 강의 흐름

도입 → 전체 지도 → 마인드셋 표지와 본문 → 상황 읽기 표지와 본문 → Frame Control 표지와 본문 → Team Playing 표지와 본문 → 사례 → 성과 기준 → 1주차 실습 → 1주차 복습 → 협상력 2주차 예고 표지 → 근거와 안전 부록.

협상력 예고 표지는 1주차 복습 뒤에 배치해 이번 주 학습이 끝났음을 먼저 닫고 다음 주로 연결한다.

## 검증 기준

- HTML에 정확히 32개의 슬라이드와 32개의 발표자 노트가 존재한다.
- 5개의 챕터 표지가 각각 독립된 슬라이드로 존재한다.
- 협상력은 예고 표지와 전체 지도·복습의 라벨 외에 이론·실습 본문에 등장하지 않는다.
- 모든 폴리오가 `01 / 32`부터 `32 / 32`까지 연속된다.
- 외부 네트워크 요청 없이 동작한다.
- 데스크톱, 와이드, 모바일 뷰포트와 32페이지 인쇄에서 잘림이 없다.
- 키보드 이동, 발표자 노트, 전체 보기, 전체 화면 기능이 유지된다.

## 범위 제외

- 2주차 협상력 강의 본문 제작
- PPTX 또는 PDF 별도 제작
- 사진이나 외부 아이콘 추가
